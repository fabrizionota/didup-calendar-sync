# Sicurezza / Security

🇮🇹 Il programma gestisce credenziali Argo, token Google e dati scolastici dei figli. Tutto resta
nella tua installazione: segreti nel `.env` (o nelle variabili dello stack), token e stato in
`data/`, mai nel repository. Non incollare in una issue log o dump non anonimizzati: i PoC hanno
`--anonimizza` apposta, e token, password e `codMin` sono sempre mascherati.

Per segnalare una vulnerabilità usa **Security → Report a vulnerability** su GitHub (segnalazione
privata), non una issue pubblica.

🇬🇧 The program handles Argo credentials, Google tokens and children's school data. Everything stays
in your installation: secrets in `.env` (or the stack variables), token and state in `data/`, never
in the repository. Do not paste non-anonymised logs or dumps in an issue: the PoCs have
`--anonimizza` for that, and tokens, passwords and `codMin` are always masked.

To report a vulnerability use **Security → Report a vulnerability** on GitHub (private report), not
a public issue.
